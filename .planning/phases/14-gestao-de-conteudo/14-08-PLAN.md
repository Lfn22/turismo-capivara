**Before:**
```typescript
app.get('/destinos/:slug', async (request, reply) => {
  const destination = await prisma.destination.findUnique({
    where: { slug },
  })
  return reply.send(destination)
})
```

**After:**
```typescript
app.get('/destinos/:slug', async (request, reply) => {
  const destination = await prisma.destination.findUnique({
    where: { slug },
  })
  
  if (!destination) {
    return reply.status(404).send({ error: 'Destino não encontrado' })
  }
  
  if (destination.approvalStatus !== 'APPROVED') {
    return reply.status(404).send({ error: 'Destino não encontrado' })
  }
  
  return reply.send(destination)
})
```

Return 404 if destination not found OR if not APPROVED. This hides PENDING/REJECTED destinations from public view.
