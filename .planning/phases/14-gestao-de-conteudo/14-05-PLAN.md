Add PATCH endpoint to packages.routes.ts for updating photos and highlights:

**PATCH /tenants/:slug/packages/:id** — Update package photos and/or highlights
```typescript
{
  preHandler: [authenticate, authorize(['ADMIN', 'CONDUTOR'])],
  schema: {
    body: z.object({
      photos: z.array(z.string().url()).max(5).optional(),
      highlights: z.array(z.string().min(5).max(200)).max(10).optional(),
    }).refine(
      (data) => data.photos !== undefined || data.highlights !== undefined,
      'At least one of photos or highlights must be provided'
    )
  }
}
handler: async (request, reply) => {
  const { id } = request.params
  const { photos, highlights } = request.body
  const userId = request.user.id
  
  try {
    let updatedPackage
    
    if (photos !== undefined) {
      updatedPackage = await packageService.updatePackagePhotos(id, userId, photos)
    }
    
    if (highlights !== undefined) {
      updatedPackage = await packageService.updatePackageHighlights(id, userId, highlights)
    }
    
    return reply.status(200).send(updatedPackage)
  } catch (err) {
    if (err instanceof AppError) {
      return reply.status(err.statusCode).send({ error: err.message })
    }
    return reply.status(500).send({ error: 'Falha ao atualizar roteiro' })
  }
}
```

Key points:
- Both photos and highlights are optional but at least one must be provided
- Updates are immediate (no approval) per D-18
- Ownership check done in service layer
- Returns updated package object
