| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-14-01 | Tampering (T) | Destination.createdById | Mitigate | API routes PATCH/DELETE must validate `User.id == Destination.createdById` before mutation (Wave 2) |
| T-14-02 | Integrity (I) | approvalStatus state machine | Mitigate | Only super-admin can modify approvalStatus (Wave 2 super-admin routes); guides cannot self-approve |
| T-14-03 | Information Disclosure (I) | TourPackage.photos URLs | Mitigate | R2 URLs are public by design; no sensitive data in photo metadata (Wave 2 upload) |
| T-14-04 | Elevation of Privilege (E) | createdById foreign key | Mitigate | FK constraint at database level prevents invalid user references |

**Disposition rationale:**
- T-14-01/02/04: Mitigate via schema constraints + API auth checks in Wave 2–3
- T-14-03: Accept — public photo URLs are intended, no secrets stored in metadata
