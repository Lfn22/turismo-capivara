## Component Contracts

### 1. Toast Provider Global — super-admin (OPS-04)

**Escopo:** Adicionar `<Toaster>` ao `apps/web/app/super-admin/layout.tsx`.

**Contrato:**
- Import: `import { Toaster } from "sonner"`
- Posição: `position="top-right"`
- Cores: `richColors` (sem override)
- Localização no JSX: último filho do elemento raiz do layout, após o `{children}`

**Remoção obrigatória em `super-admin/destinos/page.tsx`:**
- Remover: `useState<{ text: string; ok: boolean } | null>(null)`
- Remover: função `showToast`
- Remover: bloco JSX `{toastMsg && (<div role="status">...)}`
- Substituir: `showToast("texto", true)` → `toast.success("texto")`
- Substituir: `showToast("texto", false)` → `toast.error("texto")`
- Adicionar: `import { toast } from "sonner"`

**Mensagens de toast para super-admin/destinos:**

| Ação | Tipo | Mensagem |
|------|------|----------|
| Destino aprovado com sucesso | success | "Destino aprovado com sucesso." |
| Destino rejeitado com sucesso | success | "Destino rejeitado." |
| Erro ao aprovar/rejeitar | error | "Erro ao processar ação. Tente novamente." |

### 2. PainelDestinationCard — Badge de status + metadados (OPS-05)

**Escopo:** Atualizar `apps/web/src/components/ui/PainelDestinationCard.tsx`.

**Interface de dados:**
```typescript
interface PainelDestination {
  // campos existentes mantidos
  createdAt: string         // ISO 8601 — exibir como dd/MM/yyyy
  rejectionReason: string | null
}
```

**Layout do card — ordem vertical:**
1. Foto/thumbnail (existente)
2. Título do destino (existente)
3. Badge de status (NOVO — abaixo do título)
4. Data de submissão (NOVO — "Enviado em {dd/MM/yyyy}")
5. Motivo de rejeição (NOVO — visível apenas se `approvalStatus === 'REJECTED' && rejectionReason !== null`)

**Badge de status — especificação exata:**

```
padding: 4px 8px
border-radius: 9999px (pill)
font-size: 0.75rem
font-weight: 700
text-transform: uppercase
letter-spacing: 0.04em
display: inline-flex
align-items: center
```

| Status | Label PT-BR | Background | Border | Cor do texto |
|--------|-------------|-----------|--------|-------------|
| PENDING | PENDENTE | `#fffbeb` | `1px solid #fde68a` | `#92400e` |
| APPROVED | APROVADO | `#f0fdf4` | `1px solid #bbf7d0` | `#166534` |
| REJECTED | REJEITADO | `#fef2f2` | `1px solid #fecaca` | `#991b1b` |

**Data de submissão:**
- Formato: `"Enviado em " + new Date(createdAt).toLocaleDateString('pt-BR')` → "Enviado em 24/06/2026"
- Cor: `var(--stone-500)` ou equivalente cinza-médio
- Exibição: sempre visível (independente de status)

**Motivo de rejeição:**
- Exibição condicional: `approvalStatus === 'REJECTED' && rejectionReason`
- Prefixo: "Motivo: " + `{rejectionReason}`
- Cor: `#991b1b`
- Font-size: 0.8rem
- Sem ícone adicional (apenas texto)

| Elemento | Cópia |
|---------|------|
| Badge PENDING | PENDENTE |

- Nenhuma cópia nova de CTA nesta fase — OPS-01/02/03 são backend sem UI.

- "PENDENTE/APROVADO/REJEITADO" em maiúsculas pelo `text-transform: uppercase` — não hardcodar em maiúsculas no código (usar casing normal na constante de mapeamento).
