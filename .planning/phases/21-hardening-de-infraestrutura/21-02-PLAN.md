Após o schema base, usar `.superRefine()` para validação em production:

```typescript
.superRefine((data, ctx) => {
  if (data.NODE_ENV === 'production') {
    const requiredInProd = [
      'R2_ACCOUNT_ID',
      'R2_BUCKET_NAME',
      'R2_API_TOKEN',
      'R2_PUBLIC_URL',
      'ANONYMIZATION_SALT',
      'RESEND_API_KEY',
      'EMAIL_FROM',
    ] as const;
    for (const key of requiredInProd) {
      if (!data[key]) {
        ctx.addIssue({
          code: z.ZodIssueCode.custom,
          path: [key],
          message: `Variável de ambiente ausente: ${key}`,
        });
      }
    }
  }
})
```

IMPORTANTE: A mensagem de erro usa apenas o nome da variável (`key`), nunca `data[key]` (que seria o valor/secret).

Manter todos os campos existentes intactos. Não alterar a estrutura de export do módulo.
