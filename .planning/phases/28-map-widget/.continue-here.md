## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| SSR com dynamic ssr:false | Passar `dynamic(import('./X'), { ssr: false })` direto em Server Component causa crash | blocking | Sempre criar wrapper `'use client'` que importa o componente pesado |
| prisma migrate dev com drift | Schema drift existente no prod quebra migrate dev localmente | advisory | Usar `prisma db push` para mudanças de schema neste projeto |
