# BLOCKING CONSTRAINTS — Read Before Anything Else

- [ ] CONSTRAINT: MapWidgetClient wrapper — `dynamic({ ssr: false })` não pode ser usado em Server Components no App Router. Foi necessário criar `MapWidgetClient.tsx` (`'use client'`) que envolve o dynamic import. `page.tsx` importa `MapWidgetClient`, não `MapWidget` diretamente. Não reverter isso.

- [ ] CONSTRAINT: prisma migrate dev bloqueado por drift — o banco tem colunas/tabelas (PackageGuide, DepartureSlot.guideId, etc.) que não existem no histórico de migrations. `prisma migrate dev` pede reset. Usar sempre `prisma db push` para aplicar mudanças de schema neste projeto.

**Não prosseguir até checar ambas.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention |
|---------|-------------|----------|------------|
| dynamic ssr:false em Server Component | Next.js App Router proíbe — gera erro de build | blocking | Sempre criar wrapper `'use client'` para dynamic imports com ssr:false |
| prisma migrate dev | Schema drift pre-existente bloqueia migrate dev com pedido de reset | blocking | Usar `prisma db push` em vez de `prisma migrate dev` |
