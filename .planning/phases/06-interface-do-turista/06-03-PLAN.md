## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| /reservar URL params | Untrusted slotId+packageId from URL — validate before fetching |
| /confirmacao URL params | Untrusted bookingId+email+status from URL — validate email match on API |
| POST /bookings → Mercado Pago | Booking ID passed in redirect URL; Mercado Pago webhook verifies payment |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-06 | Tampering | /reservar slotId URL param | Mitigate | Fetch slot/package on page render; validate existence before showing form |
| T-06-07 | Tampering | /confirmacao email URL param | Mitigate | Server-side API validates email matches booking.customerEmail; return 404 on mismatch |
| T-06-08 | Information Disclosure | Mercado Pago redirect URL | Accept | bookingId + email public but no sensitive data (no CPF, payment token) |
</threat_model>
