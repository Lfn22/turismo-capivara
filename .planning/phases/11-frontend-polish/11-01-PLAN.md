Make two targeted changes to globals.css:

**Change 1 — AUDIT-04:** Find every occurrence of `var(--font-display), Georgia` (comma-separated, wrong) and replace with `var(--font-display, Georgia, serif)` (nested fallback, correct). The current wrong pattern uses a comma between the CSS variable and the fallback font, which means Georgia is a separate font-family value rather than a fallback within the var(). The correct form nests the fallback inside the var() call.

Also fix any occurrence of `var(--font-body), Georgia` → `var(--font-body, Georgia, serif)` if present.

**Change 2 — AUDIT-05:** Add the following CSS rule after the existing `body { ... }` block (around line 32–35 based on current file structure):

```css
input,
textarea,
select,
button {
  font-family: inherit;
  font-size: 16px;
}
```

The `font-size: 16px` is mandatory — prevents iOS Safari auto-zoom on focus. This is a global reset; do not apply per-component.

Do NOT change any other rules. Do NOT reformat existing CSS. Surgical edits only.
