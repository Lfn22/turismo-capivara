formatCurrency(amount: number, currency?: string): string

- formatCurrency(99) → "R$ 0,99"

formatDate(date: Date | string): string
- formatDate(new Date('2026-09-22')) → "22 de setembro de 2026"

formatPhone(phone: string): string
- formatPhone('11999998888') → "(11) 99999-8888"  (celular 11 dígitos)
- formatPhone('1133334444') → "(11) 3333-4444"    (fixo 10 dígitos)
- formatPhone('11999998888' com espaços/traços) → normalizar e formatar
- formatPhone('') → ''  (string vazia retorna string vazia)

- formatDate: usar Intl.DateTimeFormat com locale 'pt-BR', day: 'numeric', month: 'long', year: 'numeric'
- formatPhone: remover não-dígitos, aplicar regex para 10 ou 11 dígitos
