<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 2: Gerar e verificar favicon + ícones PWA + og-image</name>
  <what-built>
Geração de assets de imagem requer intervenção humana pois Claude não pode criar binários PNG/ICO. O manifest.json já existe. Os assets de imagem precisam ser gerados a partir do logo-animated.svg existente em apps/web/public/images/.
  </what-built>
  <how-to-verify>
Opção A (automatizada com sharp/imagemagick se disponível no sistema):

1. Verificar se imagemagick está instalado: `magick --version` ou `convert --version`
2. Se sim, executar os comandos abaixo para gerar os assets:

```bash
# favicon.ico (16x16 + 32x32)
magick apps/web/public/images/logo-animated.svg -resize 32x32 apps/web/public/favicon.ico

# apple-touch-icon (180x180)
magick apps/web/public/images/logo-animated.svg -resize 180x180 -background "#FAF5EF" -flatten apps/web/public/apple-touch-icon.png

# PWA icons
magick apps/web/public/images/logo-animated.svg -resize 192x192 -background "#FAF5EF" -flatten apps/web/public/icon-192.png
magick apps/web/public/images/logo-animated.svg -resize 512x512 -background "#FAF5EF" -flatten apps/web/public/icon-512.png
```

3. Para og-image (1200x630) — criar usando canvas/script Node.js ou ferramenta online:
   - Acesse https://og-image.vercel.app ou use Canva/Figma
   - Fundo: #FAF5EF, logo CAPI centralizado (~400px), tagline "caminho entre quem explora e quem opera" (Playfair 24px, #3D2B1F abaixo do logo), URL "capi.turismo" (bottom-right, 12px, #8B7D6B)
   - Exportar como PNG 1200x630 em apps/web/public/og-image.png

Opção B (usando script Node.js com sharp):
```bash
cd apps/web && node -e "
const sharp = require('sharp');
const svg = 'public/images/logo-animated.svg';
sharp(svg).resize(192,192).png().toFile('public/icon-192.png', console.log);
sharp(svg).resize(512,512).png().toFile('public/icon-512.png', console.log);
sharp(svg).resize(180,180).png().toFile('public/apple-touch-icon.png', console.log);
"
```
(sharp pode não estar instalado — instalar com: pnpm add --save-dev sharp em apps/web se necessário)
