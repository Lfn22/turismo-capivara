**Passo 2 — Gerar assets de imagem via script Node.js**:

Tentar a seguinte sequência de fallbacks, parando no primeiro que funcionar:

**Opção A — sharp disponível:**
```
cd apps/web
node -e "
const sharp = require('sharp');
const svg = Buffer.from(require('fs').readFileSync('public/images/logo-animated.svg'));
Promise.all([
  sharp(svg).resize(32,32).toFile('public/favicon.ico'),
  sharp(svg).resize(180,180).flatten({background:'#FAF5EF'}).png().toFile('public/apple-touch-icon.png'),
  sharp(svg).resize(192,192).flatten({background:'#FAF5EF'}).png().toFile('public/icon-192.png'),
  sharp(svg).resize(512,512).flatten({background:'#FAF5EF'}).png().toFile('public/icon-512.png'),
  sharp({create:{width:1200,height:630,channels:4,background:'#FAF5EF'}}).png().toFile('public/og-image.png'),
]).then(()=>console.log('sharp ok')).catch(e=>process.exit(1));
"
```

**Opção B — imagemagick/magick disponível** (verificar com `magick --version` ou `convert --version`):
```
magick apps/web/public/images/logo-animated.svg -resize 32x32 apps/web/public/favicon.ico
magick apps/web/public/images/logo-animated.svg -resize 180x180 -background "#FAF5EF" -flatten apps/web/public/apple-touch-icon.png
magick apps/web/public/images/logo-animated.svg -resize 192x192 -background "#FAF5EF" -flatten apps/web/public/icon-192.png
magick apps/web/public/images/logo-animated.svg -resize 512x512 -background "#FAF5EF" -flatten apps/web/public/icon-512.png
magick -size 1200x630 xc:"#FAF5EF" apps/web/public/og-image.png
```

**Opção C — placeholder via Node.js puro** (fallback final, sem dependências externas):

Gerar PNGs placeholder usando apenas o módulo `fs` do Node — escrever arquivos PNG mínimos válidos de 1x1 pixel e depois usar Canvas API se disponível, senão criar arquivos de bytes PNG mínimos. Alternativa: criar um script que grava um arquivo .png com header PNG válido de cor sólida (#FAF5EF) nas dimensões corretas usando Buffer.

Se nenhuma das opções gerar PNGs completos, criar arquivos placeholder com extensão correta contendo qualquer conteúdo binário válido e registrar no SUMMARY como "assets placeholder — substituir antes do deploy".
