<task type="auto">
  <name>Task 2: Reordenar fluxo — PIX antes do booking INSERT (PAY-02)</name>
  <files>apps/api/src/modules/bookings/bookings.routes.ts</files>
  <action>
No handler `POST /tenants/:slug/bookings`, reestruturar a sequência de operações:

**Fluxo atual (problemático):**
1. `prisma.$transaction` → lock slot, verificar capacidade, increment booked, `tx.booking.create` (sem paymentId)
2. Buscar pkg fora da tx
3. `createPixPayment()`
4. `prisma.booking.update` com paymentId/qrCode
5. (se MP falhar: compensação delete booking + restore slot)

**Fluxo novo (correto):**
1. `prisma.$transaction` → lock slot, verificar capacidade, increment booked (NÃO cria booking ainda)
   - A tx retorna `{ slot, tenant }` com os dados necessários
2. Buscar pkg fora da tx (igual ao atual)
3. `createPixPayment()` — se falhar, fazer rollback do slot em tx separada e retornar erro
4. `prisma.$transaction` → criar `booking` com todos os campos incluindo `paymentId`, `paymentUrl`, `qrCode`, `expiresAt` já preenchidos no create

Concretamente:

**Primeira tx** (apenas slot lock + increment):
```typescript
const { slotTenantId, packageId } = await prisma.$transaction(async (tx) => {
  const [slot] = await tx.$queryRaw<Array<{
    id: string
    booked: number
    capacity: number
    status: string
    packageId: string
    tenantId: string
  }>>`
    SELECT ds.id, ds.booked, ds.capacity, ds.status, ds."packageId", tp."tenantId"
    FROM "DepartureSlot" ds
    JOIN "TourPackage" tp ON tp.id = ds."packageId"
    WHERE ds.id = ${slotId}
    FOR UPDATE
  `

  if (!slot) throw new AppError('Slot não encontrado', 404)
  if (slot.tenantId !== tenant.id) throw new AppError('Slot não encontrado', 404)
  if (slot.status !== 'OPEN') throw new AppError('Slot indisponível', 400)
  if (slot.booked + pax > slot.capacity) throw new AppError('Capacidade insuficiente', 400)

  await tx.departureSlot.update({
    where: { id: slotId },
    data: {
      booked: { increment: pax },
      status: slot.booked + pax >= slot.capacity ? 'FULL' : 'OPEN',
    },
  })

  return { slotTenantId: slot.tenantId, packageId: slot.packageId }
})
```

**Buscar pkg** (igual ao atual, mas movido para antes do createPixPayment):
```typescript
const pkg = await prisma.tourPackage.findFirst({
  where: { departureSlots: { some: { id: slotId } } },
  select: {
    price: true,
    name: true,
    conductor: { select: { email: true } },
    departureSlots: { where: { id: slotId }, select: { startsAt: true }, take: 1 },

if (!pkg) {
  // Rollback slot antes de lançar erro
  await prisma.departureSlot.update({
    where: { id: slotId },
    data: { booked: { decrement: pax } },
  })
  throw new AppError('Pacote não encontrado para este slot', 500)
}
```

**createPixPayment** com rollback de slot em caso de falha:
```typescript
let paymentResult
try {
  paymentResult = await createPixPayment({
    bookingId: `pre_${Date.now()}`, // placeholder — MP usa como external_reference
    transactionAmount: Number(pkg.price) * pax,
    description: `Reserva — ${pkg.name}`,
    customerEmail,
    customerCpf,
  })
} catch (err) {
  await prisma.$transaction(async (tx) => {
    const s = await tx.departureSlot.findUnique({ where: { id: slotId }, select: { status: true } })
    await tx.departureSlot.update({
      where: { id: slotId },
      data: {
        booked: { decrement: pax },
        ...(s?.status === 'FULL' ? { status: 'OPEN' } : {}),
      },
    })
  })
  throw err
}
```
