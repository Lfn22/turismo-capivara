## What Was Built

- Campo `idempotencyKey String? @unique` adicionado ao model `Booking`
- Migration SQL: `ALTER TABLE "Booking" ADD COLUMN "idempotencyKey" TEXT` + `CREATE UNIQUE INDEX`
- Migration aplicada ao Railway PostgreSQL via `prisma migrate deploy`
- Lógica de dedup em `POST /tenants/:slug/bookings`:
  - Lê header `Idempotency-Key` (opcional)
  - Se presente: faz `prisma.booking.findUnique({ where: { idempotencyKey } })`
  - Se booking existente pertence ao mesmo tenant: retorna `200` com booking existente
  - Se chave nova: cria booking normalmente salvando a chave no campo `idempotencyKey`
  - Se header ausente: comportamento anterior mantido (`idempotencyKey: null`)
