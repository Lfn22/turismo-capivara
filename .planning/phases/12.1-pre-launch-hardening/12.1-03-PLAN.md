**Pré-requisito:** Ter o slug de um tenant existente em produção (ex: `demo` ou o slug real). Ter a URL da API em produção (Railway).

---

**Passo 1 — Criar booking com PIX**
```bash
curl -s -X POST https://SEU-API.up.railway.app/tenants/SEU-SLUG/bookings \
  -H "Content-Type: application/json" \
  -d '{
    "slotId": "ID-DE-UM-SLOT-OPEN",
    "customerName": "Smoke Test",
    "customerEmail": "seu-email@exemplo.com",
    "customerPhone": "11999999999",
    "customerCpf": "12345678901",
    "pax": 1
  }'
```
Resultado esperado: `{"id": "...", "status": "PENDING", "qrCode": "...", "paymentUrl": "..."}`

Anote o `bookingId` retornado.

---

**Passo 2 — Verificar QR Code**
Confirmar que o campo `qrCode` na resposta não está vazio e contém uma string longa (código PIX válido começa com `00020126...`).

---

**Passo 3 — Simular webhook do Mercado Pago**
```bash
curl -s -X POST https://SEU-API.up.railway.app/webhooks/mercadopago \
  -H "Content-Type: application/json" \
  -d '{
    "action": "payment.updated",
    "data": { "id": "PAYMENT-ID-DO-BOOKING" }
  }'
```
**Observação:** O campo `PAYMENT-ID-DO-BOOKING` é o `paymentId` retornado no passo 1. O webhook real do MP usa este id para buscar o status. Em ambiente de teste, você pode verificar o comportamento observando os logs do Railway.

Alternativa se o webhook requer assinatura HMAC: verificar os logs do Railway para o request de webhook do MP após simular um pagamento no sandbox do MP.

---

**Passo 4 — Verificar status CONFIRMED**
```bash
curl -s https://SEU-API.up.railway.app/tenants/SEU-SLUG/bookings/lookup \
  -X POST \
  -H "Content-Type: application/json" \
  -d '{"email": "seu-email@exemplo.com", "code": "ULTIMOS-4-CHARS-DO-BOOKING-ID"}'
```
Resultado esperado após webhook: `{"status": "CONFIRMED", ...}`

---

**Passo 5 — Verificar email recebido**
Checar a caixa de entrada do email usado no Passo 1. Email "Reserva confirmada — CAPI" deve ter chegado.

---

**Passo 6 — Verificar página /acesso**
Acessar `https://SEU-DOMINIO/acesso` no browser (mobile e desktop) e confirmar que a página carrega com todas as 5 seções.
