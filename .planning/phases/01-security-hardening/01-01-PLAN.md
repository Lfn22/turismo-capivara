  <action>
Edit apps/api/src/app.ts to add a global error handler that serializes AppError instances.

1. Add AppError import at the top with the other imports:
   ```typescript
   import { AppError } from './shared/errors/AppError'
   ```

2. After all `app.register(...)` calls and before the `start()` function, add:
   ```typescript
   app.setErrorHandler((err, _request, reply) => {
     if (err instanceof AppError) {
       return reply.status(err.statusCode).send({ message: err.message })
     }
     app.log.error(err)
     reply.status(500).send({ message: 'Erro interno do servidor' })
   })
   ```

This handler means that any route file (plans 01-02, 01-03, 01-04) can `throw new AppError('message', statusCode)` and get the correct HTTP response without wrapping every handler in try/catch for AppError specifically.

The `app.log.error(err)` line ensures unexpected errors are still logged before the 500 response.
