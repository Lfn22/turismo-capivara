  <action>
  Add `fastify-raw-body` import and registration to `apps/api/src/app.ts`.

  The plugin MUST be registered BEFORE any route plugins. This is required because `fastify-raw-body` adds `rawBody` to each request, and the webhook handler in plan 04-03 needs `req.rawBody` as a Buffer for HMAC validation.

  **Step 1 — Add import at top of file** (after existing imports):
  ```typescript
  import rawBody from 'fastify-raw-body'
  ```

  **Step 2 — Register plugin BEFORE any route registrations.**

  Add immediately after `const app = Fastify({ logger: true })`:

  ```typescript
  await app.register(rawBody, {
    field: 'rawBody',
    global: false,
    encoding: false,
    runFirst: true,
  })
  ```

  Wait — `fastify-raw-body` v4+ registers synchronously in Fastify 5. Use:

  ```typescript
  app.register(rawBody, {
    field: 'rawBody',
    global: false,
    encoding: false,
    runFirst: true,
  })
  ```

  `global: false` means raw body is only captured on routes that explicitly set `config: { rawBody: true }`. The webhook route (plan 04-03) will set this config. Other routes are unaffected.

  The registration must appear BEFORE `app.register(authRoutes)` and all other route registrations. After cors and helmet but before JWT or routes is acceptable.

  **Correct registration order in app.ts:**
  1. `rawBody` plugin (new)
  2. `cors`
  3. `helmet`
  4. `jwt`
  5. route plugins (authRoutes, tenantsRoutes, etc.)

  If fastify-raw-body v4 exports differ, check the module: `import rawBody from 'fastify-raw-body'` is the correct default import per the package documentation.
  </action>
